# Alpha_Forecast
This project is a machine learning–based stock market prediction application that uses a Long Short-Term Memory (LSTM) neural network to analyze historical stock price data and predict future price movements. The model is trained on time-series data such as open, high, low, close, and volume, which is preprocessed using normalization and sliding window techniques to capture temporal dependencies.

Historical stock data is fetched dynamically using the Yahoo Finance API, and the trained model predicts future prices based on learned patterns. The application is deployed using Streamlit, providing an interactive interface where users can input a stock symbol and visualize actual vs predicted prices through graphs.

This project demonstrates practical experience in time-series analysis, deep learning with LSTM, data preprocessing, model evaluation, and end-to-end ML application deployment.
